04 / LimitsBefore you set it up

What doesn't work yet

Worth knowing before you set it up.

  1. Not every Craft app is here

    EffectCraft, FilmCraft, CADCraft, GridCraft and LightCraft can't yet be locked to one person's folder, so I didn't host them. Fixes for all five are in review upstream, linked under the apps. The status page shows what's running now.

  2. Generation uses your ArtCraft grant

    On Studio, image and video generation and library reads use a separate ArtCraft token, not the connector sign-in. A paid job starts only after you agree to the price. The local server, which runs on Windows, macOS and Linux, can do the same with an API key that stays on your computer.

  3. The apps run without their windows

    Anything that needs the desktop app, such as printing, isn't available.

  4. Files are capped

    Up to 500 MB each and 5 GB per account.

  5. One server, run by one person

    If something breaks, open an issue.

05 / AboutIndependent · not official

Who runs this

I'm Adithya Shankaran. ArtCraft brings Storytold's open-source Craft apps together on the desktop, and I built BridgeCraft to extend those same apps into ChatGPT, Claude and other assistants.

It is not an official Storytold or ArtCraft product. I've proposed that Storytold adopt it, and you can follow that in RFC-0016. The code is Apache-2.0 on GitHub, and the list of changes is in its commit history.

06 / Set it upClaude · ChatGPT · Cursor · VS Code

Set it up

Pick where you use AI. In Claude or ChatGPT it's one address and a sign-in; in the coding tools it's one command.

{# Tabs once site.js runs; without it every panel shows, one under the other. #}
Connector address
{{ site_url }}/studio
  1. In Claude or ChatGPT, open Settings and add a custom connector.
  2. Paste the address above and save.
  3. Sign in when it asks. It then works on the web, the desktop app and your phone.
Terminal
claude plugin install bridgecraft --marketplace adikshan11/bridgecraft
Or without the plugin
claude mcp add --transport http bridgecraft {{ site_url }}/studio
Or ask Claude Code
Add the BridgeCraft MCP server at {{ site_url }}/studio over HTTP, then open /mcp so I can sign in.

Add to Cursor

Or in ~/.cursor/mcp.json
{
  "mcpServers": {
    "bridgecraft": { "url": "{{ site_url }}/studio" }
  }
}
Terminal
code --add-mcp '{"name":"bridgecraft","type":"http","url":"{{ site_url }}/studio"}'
